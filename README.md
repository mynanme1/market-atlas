# Market Atlas · 市场图谱

Local-first financial research, dated evidence and paper-trading experiments.

把公司卡片、行业与产业链、证据、研究判断和模拟交易连接起来的本地研究工作台。**不是券商软件，不连接真实资金，也没有被证明能够稳定盈利。**

## 能做什么

- 公司卡片与多行业、多产业链归属，区分供应关系和研究推断。
- 驱动因素、情景与来源记录；将长期基本面判断和短期入场条件分开。
- 日期敏感的证据筛选，区分公开日期与系统录入日期。
- 本地模拟账户、订单与价格图表；第三方行情需要联网且不保证可用。
- 策略研究引擎和完全合成的可重复测试，不以私人历史收益作为宣传。

这是从个人研究项目整理出的实验性首版，功能与测试仍在完善。内置公司、观点、事实摘记和概率参数只是结构示例，不是最新核验结论。资料完整不等于投资正确。

## 四个工作区

新版按研究流程整理为四个主入口，原功能保留在二级视图中：

| 工作区 | 用途 |
| --- | --- |
| 今日工作台 | 检查已收录资料、资料缺口和组合状态，明确数据日期 |
| 研究中心 | 在同一公司下查看研究判断、证据、财务估值、关系及模拟记录 |
| 策略实验室 | 查看当前规则、运行回测、研究因子，按需打开历史实验 |
| 模拟组合 | 分开查看持仓、行情与候选、下单与记录 |

公司选择和研究子视图保留在 URL 中，支持刷新及浏览器前进、后退。页面切换不会自动下单或启动回测；本次整理不改变既有评分与交易参数。详见 [工作区架构](docs/workspace-architecture.md)。

## 本机运行

推荐 Node.js 24 LTS、npm 和 Git。无需 Cloudflare 账号；D1 在本地模拟运行。

```sh
git clone https://github.com/mynanme1/market-atlas.git
cd market-atlas
npm ci --include=dev --include=optional
npm run dev
```

浏览器打开 <http://localhost:3000>。**终端中的服务进程必须保持运行**；关掉终端或重启电脑后，需要重新运行 `npm run dev`。端口拒绝连接通常表示服务没启动，不需要开放防火墙或路由器端口。

首次读取应用会自动建立本地表和示例记录。数据存放在 `.wrangler/`，不会提交到 Git。停止服务后可自行备份该目录；升级前建议备份。本版没有完善的数据库升级/恢复工具。

```sh
npm test
npm run audit:release
npm run demo:backtest
npm run build
npm start
```

开发服务和生产预览不要同时占用 3000 端口。`demo:backtest` 只运行虚构公司和合成价格，不联网、不生成账户订单；输出收益不代表真实策略效果。

## 开源版与个人研究档案的边界

| 包含 | 不包含 |
| --- | --- |
| 应用源码、研究规则、表结构与锁文件 | 维护者本地数据库、个人订单和原 Git 历史 |
| 合成输入、自动化测试 | 第三方原始行情、财报全文与下载缓存 |
| 档案格式与缺资料提示 | 私人回测报告和已经得出的历史收益结论 |

历史研究面板没有资料时显示“未导入”，不是零收益。部分面板支持页面顶部的 JSON 导入（仅浏览器内存，刷新即清除）；其他旧式静态报告面板保留缺资料状态。它们不是通用数据分析器，支持的格式见 [档案说明](docs/ARCHIVES.md)。

原本依赖私人输入的 `/api/execution-backtest` 在本发行版返回 409 和说明，不假装已经完成回测。本地模拟账户接口仍保留。开源发行版不是原个人工作目录的完整数据副本。

## 数据与研究限制

使用实际行情前，请核对数据服务条款、时效、复权、拆股、分红、汇率和交易日。接口可能延迟、限流或改变格式。历史财报在公开前不能进入信号；后来补录的资料只能标注为历史重建，不能冒充实盘当时已知。

当前成交模型不完整覆盖实际撮合、涨跌停、停牌、借券、税费和市场冲击。反复调参的区间不是独立样本外检验。详情见 [数据政策](docs/DATA_POLICY.md)。

## 技术与安全

React / TypeScript / Vinext + Vite / Drizzle / 本地 Cloudflare D1。

- `app/`：界面与本地 API；`app/research/`：研究规则。
- `db/`、`drizzle/`：数据库定义；`examples/`、`tests/`：合成验证。
- `scripts/`：演示与发布检查；`.github/workflows/`：CI。

默认只监听 localhost。尚无多人登录、权限隔离、完整请求校验和公网安全加固，**不要暴露端口或开公网隧道**。构建成功不等于完整类型检查或安全认证，参见 [已知限制](docs/KNOWN_LIMITATIONS.md)。
