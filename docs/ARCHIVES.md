# 历史研究档案

仓库不附带维护者私人研究报告。八个历史面板使用 `ResearchArchiveBoundary`：缺资料时显示提示；字段检查失败时不导入；渲染失败时显示格式不匹配，而不是隐藏成零收益。

支持的九种文件名与结构位于 `app/research/archive-contracts.json`，对应 TypeScript 类型位于 `archive-types.ts`。这是现有专用实验视图的格式，不是通用财报上传器，也不能直接读 PDF。选择器可一次加载多个相关 JSON。

文件限制：每个 8 MB、有限嵌套深度与节点数；拒绝原型污染字段、非有限数值以及非 HTTP(S) 的 URL 字段。检查只验证结构，不能证明事实可靠、来源授权或结果无偏差。旧实验中的固定阈值及文字仅适合该实验。

文件不上传、不写入数据库，刷新页面会清除。没有资料时，请先运行 `npm run demo:backtest` 学习研究流程，不能编造证据来填满面板。

少数旧静态面板仍读取 `/research/` 路径并展示缺资料状态；这个目录被 Git 忽略，不在本发行版中提供私人报告。旧面板中的结果下载链接只有使用者自行提供相应合法静态档案时才可用。

宏观历史观测默认空白，保留模型代码与公司敏感度假设；缺失宏观输入不等于经济处于中性周期。维护者私人输入的 execution-backtest API 已禁用；合成演示不替代真实样本外检验。
