# 工作区架构整理

本轮定位：信息架构与页面拆分，不改变研究评分、交易规则或数据库结构。

## 四个稳定入口

| 入口 | 职责 | 次级内容 |
| --- | --- | --- |
| 今日工作台 | 确定本次研究入口 | 资料公开日期、资料缺口、待成交记录、行情记录日期 |
| 研究中心 | 以公司为单位组织研究 | 判断、原始资料与事实、财务估值、产业关系、模拟记录 |
| 策略实验室 | 定义与检验方法 | 当前规则、历史回测、因子研究、实验归档 |
| 模拟组合 | 执行与复盘 | 持仓概览、行情与候选、下单与记录 |

行业网络、驱动情景、专业分析、证据维护工具保留为研究中心的二级入口。
历史实验按选择载入，不再整页堆叠到模拟盘。

## 代码边界

- `app/page.tsx`：应用壳、导航、数据读取、公司卡片编辑。
- `app/workspace/model.ts`：研究数据类型，沿用现有接口字段。
- `app/workspace/navigation.mjs`：四入口与子视图 URL；保留公司选择，支持刷新、前进和后退。
- `TodayWorkspace.tsx`：只读摘要，不生成新的推荐评分。
- `ResearchCenter.tsx`：同一公司上下文的多视图；资料缺失不以零值或示例数据替代。
- `StrategyWorkspace.tsx`：策略工具路由，按需载入旧实验。
- `StrategyBacktestWorkspace.tsx`：从模拟盘提取的原回测逻辑与图表。
- `strategyRules.ts`：策略实验室与模拟组合共用的原规则配置。
- `PaperTradingDashboard.tsx`：保留原评分和执行，分开持仓、行情、订单。
- `workspace.css`：新壳与公司研究样式；不重写旧业务页面的全部样式。

## 本轮不做

- 不以打开页面或切换标签触发下单、行情刷新或回测。
- 不修改账户、订单、持仓、证据记录或交易参数。
- 不把历史实验结果自动提升为当前策略。
- 不宣称新架构已经统一所有旧模块的评分模型。

## 验证与发行边界

- 新增工作区测试覆盖四入口、URL 公司上下文、证据来源、缺失指标和回测分离。
- 原有开源版合成测试与档案边界测试继续保留。
- 本次开源版验证：25 项自动化测试通过，生产构建通过，发布扫描未发现禁带文件、密钥模式或私人档案依赖。
- 构建和发布检查通过后发布；不将个人数据库、真实账户订单或私人回测档案加入开源版。
- 本地完整工作区另做过浏览器导航与只读检查；该检查不代表开源版包含相同研究数据。

全项目类型检查的已知限制见 [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md)。构建通过不代表完整类型检查或策略有效性认证。

后续可逐步把旧业务大组件拆成领域服务，但应先补统一口径测试，再改评分或交易逻辑，避免把页面重构与策略实验混为一次变更。
