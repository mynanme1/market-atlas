# 首版已知限制

- 原项目仍有严格 TypeScript 检查欠账（Worker/D1 类型及部分推断），构建不执行完整类型检查。CI 当前测试关键纯函数与构建，不宣称全项目类型检查或完整浏览器端到端通过。
- 档案视图面向原实验结构，空案例或不匹配版本可能触发受控错误提示；并非任意 JSON 分析器。
- 部分静态历史报告在开源版中缺省，不能靠克隆代码重现维护者未公开的实验收益。
- 种子研究不是当前实时数据，行情服务也没有可用性保证。宏观观测数据未随仓库发布。
- 数据库尚无完善的版本迁移与恢复向导；升级前备份本地状态。
- 本地 API 尚未经过完整输入校验、CSRF、多用户隔离和安全审计。只适合可信本机环境。
- 撮合、成本、市场规则和币种转换是假设模型；不支持真实券商下单。
- 研究策略并未完成独立样本外有效性证明。合成测试只检查行为，不能证实赚钱能力。

优先改进方向：完整类型检查、更多 API 校验与合成集成测试、合法数据适配器、统一档案导入、版本迁移、跨平台与浏览器回归。
