# 数据政策与研究边界

## 代码开源不等于数据开放

本仓库发布代码、表结构和合成测试。个人数据库、订单、研究档案、财报全文和第三方原始行情不随源码发布。用户自行确认数据获取、存储、分析及再分发权限；可在网页访问不等于可复制再分发。

示例记录中的公司名、股票代码、短业务描述、公开来源链接与研究假设仅演示产品结构；来源链接不代表已完成当日核验，也不表明网站或发行人认可本项目。不能用示例概率和评分直接指导交易。

## 时间与可重复性

- 每条事实应保存报告期、公开时间、录入时间、来源位置、单位与修订版本。
- `published` 模式是按公开时间进行历史重建；`recorded` 模式还限制系统录入时间。两者不能混称真实历史实盘。
- 发布日只有日期、无时间时，应采用保守可用时点，避免当日收盘前已知的假设。
- 价格要核对币种、复权、拆股、分红、汇率、交易时区、停牌和缺失值。
- 对照策略保持相同选股范围、资金、成本和观察区间；报告调参次数及未采用结果。
- 仓位、现金、成交、费用、已实现与未实现收益必须能对账。

## 本地保存

应用数据库在 `.wrangler/`；研究 JSON 导入仅保存在当前浏览器内存。本项目没有远程同步备份承诺。删除本地目录前请自行备份。不要将带账户信息的数据库用于公开 issue。

## 不作出的承诺

不保证接口持续可用、行情实时、数据完整、实盘可成交或策略盈利。证据覆盖率仅是资料状态，不是利好程度；相关性不是因果；回测收益不是未来收益。
